# 透明食品安全｜家庭食用油安全專題 v1.44

這是一個提供家庭使用的食用油事件查詢與資料整理網站。資料更新至 2026/09/08 23:00（Asia/Taipei）；本網站不是政府官方網站，實際下架、回收與處置仍以主管機關最新公告為準。

本版重新安排手機、iPad 與桌機首頁，讓「核對家中的油」成為第一個操作。免登入、不保存查詢個資、不讀取發票載具。

## 使用方式

輸入品牌、商品名稱或條碼，再選填瓶身有效日期。查詢會列出所有相符紀錄；沒有找到、或日期不符，都不代表商品安全。請核對每筆來源的下架與回收範圍。

相機辨識取決於瀏覽器支援；部分 iPad 不支援時，可改用文字輸入。相機影像不會上傳。

## 本次更新

- 臺北市衛生局第4波抽驗 43 件市售油品，確認 4 個已先行預防性下架的麻油產品不合格：麻油車冷壓黑麻油 255mL 效期 2028/02/23、2028/05/03，BaP 分別為 2.2、2.3 μg/kg；金葫蘆特級胡麻油 3L 效期 2028/04/28、2028/05/15，分別為 3.4、2.8 μg/kg。
- 麻油車冷壓黑麻油效期 2028/05/03 已由「列入回收範圍」修正為「檢驗不合格」。效期 2028/06/24 仍只有回收處置、未公開個別檢驗值。
- 金葫蘆特級胡麻油 3L 新增兩個確認不合格效期；原本效期 2028/08/13 維持「下架回收範圍」，不把其他批次的檢驗值套用於它。
- 永利油廠特級胡麻油檢出 BaP 2.9 μg/kg；金葫蘆特級胡麻油 3L（2028/08/13）與好時來小磨香油 3L（2028/08/18）分別列為下架回收產品，不把上游檢體數值套用到兩款成品。
- 惠家香南瓜籽油 250mL（2028/03/11）列為不合格；臺北官方公告 3.0 μg/kg、桃園相關報導 3.2 μg/kg，保留來源差異，未自行平均或推定為複驗差異。北市全聯進貨384瓶、已退貨328瓶；其他批號預防性下架另行標示。
- 同廠苦茶油、亞麻仁油與小磨香油屬臺北市衛生局抽驗範圍，截至資料截點尚未公布不合格結果，因此未列入問題產品。
- 德記頂級小菓苦茶油 600mL（2027/07/20）新增為媒體引述衛生局抽驗 2.8 μg/kg；官方原始結果頁待補。
- 高仰三兩個已確認超標效期分列；麻油車三個回收效期也分列，只有 2028/04/06 具有公開的 3.2 μg/kg 結果。
- 由豐將苦茶油（100%）改為已確認不合格批次；保留舊的預防性下架紀錄供追溯。
- 中聯案的強制下架與可重新上架清單仍分開保留，歷史清單不直接當成今日判定。
