## 透明食品安全｜家庭食用油安全專題 v1.40

這是一個提供家庭使用的食用油事件查詢與資料整理網站。資料更新至 2026/08/21；本網站不是政府官方網站，實際下架、回收與處置仍以主管機關最新公告為準。

v1.40 新增的重點

* 南投縣信義鄉農會苦茶油新增為問題產品，涉及有效日期 2027/03/19、2027/05/06 兩批次。
* 公開檢驗結果為苯駢芘（BaP）5.4 μg/kg，高於法定限量 2.0 μg/kg；請停止食用並依公告辦理回收。
* 南投信義鄉農會列為品牌／責任業者，彰化再源油品興業有限公司列為委託代工廠。
* 彰化二水益興製油工廠、臺中協昌油廠及沙鹿油行目前僅列為跨縣追查方向，尚未寫成已確認的責任供應鏈。
* 商品介紹頁標示苦茶籽為中國進口、製造地為臺灣；原料產地與 BaP 污染原因分開記錄，不互相推論。
* 嘉義信安／源春事件與南投信義鄉農會事件維持分開，避免將不同案件誤合併。

v1.40 整合內容

* 首頁：苦茶油與中聯油脂兩條主線，兩案均加入「事件時序表」與「我們的整理」入口。
* 苦茶油事件時序：補入南投、彰化跨縣追查及最新產品狀態。
* 中聯油脂事件時序：保留地方抽驗缺口、原料轉換與放寬標準、三大股東治理關聯及司法進度。

## 時序表品牌／產品字重規則

- 若來源明確顯示企業與下架回收商品的品牌、產品責任、採購、委託製造、分裝貼標或供應鏈追查有關，時序表須將該企業名稱與相關商品名稱列入加重字體。
- 企業即使同時具有通路或訂購方身分，只要與下架回收商品存在上述關聯，不得視為單純通路商而略去；永豐餘及相關問題產品適用此規則。
- 僅有物流、販售或通路關係，且沒有產品責任或下架回收關聯證據者，維持一般字重。
