## 透明食品安全｜家庭食用油安全專題 v1\.43

這是一個提供家庭使用的食用油事件查詢與資料整理網站。資料更新至 2026/09/06 23:00（Asia/Taipei）；本網站不是政府官方網站，實際下架、回收與處置仍以主管機關最新公告為準。

本版重新安排手機、iPad 與桌機首頁，讓「核對家中的油」成為第一個操作。免登入、不保存查詢個資、不讀取發票載具。

## 使用方式

輸入品牌、商品名稱或條碼，再選填瓶身有效日期。查詢會列出所有相符紀錄；沒有找到、或日期不符，都不代表商品安全。請核對每筆來源的下架與回收範圍。

相機辨識取決於瀏覽器支援；部分 iPad 不支援時，可改用文字輸入。相機影像不會上傳。
