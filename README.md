## 版本編號規則

- 目前正式發布網站版號維持 `v1.37`；本次工作中的內部修訂不直接跳升正式版號。
- 自下一次正式發布起，正式版號由 `v1.40` 開始。
- 日常工作對話與內部檔案修訂，使用當時網站最新版號加英文字母後綴：例如正式網站為 `v1.37` 時，依序使用 `v1.37a`、`v1.37b`……`v1.37z`。
- 只有在實際發布新網站時，才將內部後綴版號改成下一個正式版號；README、網站頁尾、資料庫檔名與 ZIP 檔名須同步更新。
- 未正式發布的內部修訂，不得自行改寫成 `v1.38` 或 `v1.39`，避免 README 版本紀錄跳號。

## 時序表品牌／產品字重規則

- 若來源明確顯示企業與下架回收商品的品牌、產品責任、採購、委託製造、分裝貼標或供應鏈追查有關，時序表須將該企業名稱與相關商品名稱列入加重字體。
- 企業即使同時具有通路或訂購方身分，只要與下架回收商品存在上述關聯，不得視為單純通路商而略去；永豐餘及相關問題產品適用此規則。
- 僅有物流、販售或通路關係，且沒有產品責任或下架回收關聯證據者，維持一般字重。
